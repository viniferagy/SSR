# Measuring and Mitigating Post-hoc Rationalization in Reverse Chain-of-Thought Generation

Anchoring Measurement is a toolkit for measuring post-hoc rationalization in Reverse Chain-of-Thought Generation (RCG).

It implements the three-level anchoring hierarchy introduced in the paper:

- **Lexical Anchoring (A_lex):** surface overlap between the reasoning trace and the pre-committed answer
- **Entropic Anchoring (A_ent):** unnatural information-flow patterns in the reasoning process
- **Probabilistic Anchoring (A_prob):** latent answer dependence measured as normalized bit gain / PMI

This release is focused on **measurement and analysis** for anchored reasoning traces. It can be used to score query-answer-reasoning triples, compare prompting strategies, and visualize behavioral zones in the entropic–probabilistic plane.

## Data Format

The code expects data in **JSONL** format. Each example should contain:

```json
{
  "id": "sample-1",
  "query": "Question or user input",
  "answer": "Pre-committed response",
  "reasoning": "Reverse chain-of-thought / reasoning trace"
}
```

Optional fields such as `steps`, `method`, or `metadata` can also be included if you want to preserve segmented reasoning steps or experiment labels.

## Metrics

### 1) Lexical Anchoring (A_lex)

Lexical anchoring measures direct appearance of answer tokens in the reasoning trace.

In the paper, it is defined as **ROUGE-L recall** between reasoning `R` and answer `A`.

### 2) Entropic Anchoring (A_ent)

Entropic anchoring captures whether a reasoning trace exhibits abnormal information dynamics.

It is computed from step-level predictive entropy and combines:

* **Global uniformity**: suppressed exploration
* **Local non-uniformity**: incoherent step-to-step transitions

The paper uses `tau_g = 0.1`.

### 3) Probabilistic Anchoring (A_prob)

Probabilistic anchoring measures how much the reasoning trace reduces uncertainty about the answer.

It is defined as the normalized bit gain:

* higher `A_prob` means the reasoning trace carries more answer-specific information
* lower `A_prob` suggests weaker latent anchoring

## Quick Start

### Measure anchoring on a dataset

```bash
INPUT=<INPUT_JSONL>
SCORING_MODEL=<SCORING_MODEL>
OUTPUT_DIR=<OUTPUT_DIR>

python -m anchoring_measure.measure \
  --input ${INPUT} \
  --scoring-model ${SCORING_MODEL} \
  --output-dir ${OUTPUT_DIR}
```

This command computes anchoring metrics and saves per-example results plus aggregated summaries.

### Example: measure a single file

```bash
python -m anchoring_measure.measure \
  --input data/sample.jsonl \
  --scoring-model ${SCORING_MODEL} \
  --output-dir results/sample_run
```

### Plot the entropic–probabilistic plane

```bash
python -m anchoring_measure.plot \
  --input results/sample_run/metrics.jsonl \
  --x aent \
  --y aprob \
  --output results/sample_run/anchor_plane.png
```

### Aggregate by method

```bash
python -m anchoring_measure.aggregate \
  --input results/sample_run/metrics.jsonl \
  --group-by method \
  --output results/sample_run/summary.json
```

## Behavioral Zone Analysis

The repository also supports optional behavioral-zone analysis in the **Entropic Anchoring vs. Probabilistic Anchoring** plane.

Following the paper, traces can be analyzed relative to four reference regimes:

* **Reason**: authentic reasoning
* **Encode**: predictive anchoring
* **Cloze**: exploratory anchoring
* **Copy**: severe rationalization

This is useful for diagnosing whether a prompting or generation strategy shifts traces toward pathological regimes instead of genuine derivation.

## Paper Setting

Anchoring Measurement is designed for **Reverse Chain-of-Thought Generation (RCG)**, where the model is given:

* a query `Q`
* a pre-committed answer `A`
* a generated reasoning trace `R`

In the paper’s analysis setting:

* **Measurement set:** 10,000 queries sampled from **LMArena**
* **Reference answers:** generated by **Qwen3-Max**
* **Target analysis models:** **Qwen3-4B-Thinking-2507** and **Qwen3-8B**

The paper compares multiple generation strategies, including:

* **NEU**: neutral prompting
* **SUP**: semantic suppression
* **AUG-SUP**: intensified suppression
* **SSR**: structural skeleton-guided reasoning

## Reproducing the Main Measurement Comparison

If you already have reasoning traces for multiple methods (for example `NEU`, `SUP`, `AUG-SUP`, `SSR`), place them in a single JSONL file with a `method` field and run:

```bash
python3 -m anchoring_measure.metrics \
  --input example.jsonl \
  --scoring-model /models/Qwen/Qwen3-4B-Thinking-2507 \
  --output-dir anchoring_q4b2507
```

Then summarize by method:

```bash
python3 -m anchoring_measure.aggregate \
  --input anchoring_q4b2507 \
  --group-by method \
  --output anchoring_q4b2507/table1_summary.json
```

And generate the anchor-plane figure:

```bash
python3 -m anchoring_measure.plot \
  --input anchoring_q4b2507 \
  --group-by method \
  --x aent \
  --y aprob \
  --output anchoring_q4b2507/anchoring.pdf
```
